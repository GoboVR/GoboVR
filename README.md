# GoboVR

I build random things and try to maintain them, mostly experiments or just something I wished I had in my life.

Organization I'm a part of with a friend: [SpiritEXEWasTaken](https://github.com/SpiritEXEWasTaken)

## Projects

- **[ThorWoA](https://github.com/ThorWoA)**: A port of Windows 11 to the Ayn Thor Max.
- **[PipeVR](https://github.com/SpiritEXEWasTaken/PipeVR)**: An all-in-one media streaming app for Android VR headsets.
- **[CleanMyVR](https://github.com/SpiritEXEWasTaken/CleanMyVR)**: A cleanup tool for Meta Quest headsets.
- **[RGS](https://github.com/SpiritEXEWasTaken/RGS)**: A Rust game server for Unity.
- **JellyVR**: A Jellyfin client for Android VR headsets. Not on GitHub yet.
- **[MegaMix+ Mod Manager](https://github.com/GoboVR/megamix-mod-manager)**: A mod manager for Hatsune Miku Project DIVA MegaMix+.
- **[Immich Photo Frame](https://github.com/GoboVR/immich-photo-frame)**: An Android photo frame app that displays photos from Immich.
